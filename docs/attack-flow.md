# Attack Flow

## Phase 1: Reconnaissance

The attacker identifies employees using publicly available sources such as LinkedIn.

## Phase 2: Initial Access

A phishing email is sent impersonating the company's IT department.

The email contains a link to a fake login page.

## Phase 3: Credential Capture

A user enters their username and password on the phishing page.

The attacker now possesses valid credentials.

## Phase 4: Unauthorized Access Attempt

The attacker attempts to log in from an unusual geographic location.

Security monitoring tools detect suspicious login activity.

## Phase 5: Detection

Login monitoring triggers an alert due to unusual sign-in behavior.

## Phase 6: Response

The security team investigates the activity and forces a password reset.
