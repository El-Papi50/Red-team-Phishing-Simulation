# Attack Scenario

This tabletop simulation demonstrates a phishing-based credential compromise.

## Environment

Organization: Small technology company  
Users: 50 employees  
Security tools: Email filtering, login monitoring, endpoint protection

## Attack Narrative

An attacker launches a phishing campaign targeting employees.

The phishing email impersonates the IT department and asks users to reset their password.

A victim clicks the link and enters credentials on a fake login page.

The attacker attempts to use these credentials to access the organization's services.

Unusual login activity triggers security alerts, and the security team begins an investigation.

## Goal of Simulation

To analyze the attack path and identify opportunities for detection and response.
