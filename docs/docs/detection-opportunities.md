# Detection Opportunities

Security teams can detect phishing-led credential compromise through several signals.

## Email Security

• Suspicious sender domain  
• Links to external login pages  
• Email impersonation attempts

## Authentication Monitoring

• Login attempts from unusual geographic locations  
• Login from new devices  
• Multiple failed login attempts

## Account Behavior

• Sudden mailbox rule creation  
• Unusual account activity  
• Changes to authentication settings

## Security Controls

• Multi-factor authentication
• Phishing awareness training
• Conditional access policies
