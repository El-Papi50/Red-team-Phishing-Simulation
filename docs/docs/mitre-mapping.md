# MITRE ATT&CK Mapping

| Attack Stage | MITRE Technique | ID |
|--------------|----------------|----|
| Phishing Email | Phishing | T1566 |
| Credential Use | Valid Accounts | T1078 |
| Remote Login Attempt | External Remote Services | T1133 |
| Email Data Access | Email Collection | T1114 |

## Explanation

Phishing is commonly used to obtain valid credentials.

Once credentials are stolen, attackers may attempt to log into systems using legitimate authentication processes.
