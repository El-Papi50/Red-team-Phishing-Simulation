# Incident Report

## Incident Summary

A suspicious login attempt was detected from an unfamiliar location.

Further investigation revealed that a user had entered credentials into a phishing page.

## Impact

No confirmed data exfiltration occurred.

However, the account was temporarily compromised.

## Actions Taken

• User password reset  
• Account sessions revoked  
• Phishing email blocked

## Lessons Learned

Phishing awareness training and stronger email filtering could reduce risk.
