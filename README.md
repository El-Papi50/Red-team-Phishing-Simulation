# Red Team Phishing Simulation Lab

This repository contains a red-team style tabletop simulation demonstrating how a phishing attack can lead to credential compromise and potential account misuse.

The goal of this project is to analyze the attack path, map activities to the MITRE ATT&CK framework, and identify detection and response opportunities.

This project does NOT contain malware, exploit code, or offensive tooling. It is intended strictly for cybersecurity learning and defensive analysis.

---

## Project Objectives

• Understand how phishing campaigns lead to credential compromise  
• Map attacker activity to the MITRE ATT&CK framework  
• Identify detection opportunities for security teams  
• Demonstrate incident documentation and response analysis  

---

## Attack Scenario

A phishing email impersonating IT support is sent to an employee.  
The victim clicks a malicious login link and unknowingly enters their credentials.

An attacker then attempts to use the stolen credentials to access internal systems.

The organization’s monitoring tools detect suspicious login activity and initiate an investigation.
